# 迭代快照: v0.3.0 - 2026-03-23

## 变更摘要

集成 CFR 反编译工具，实现二方件精准 Mock。支持自定义 Maven 仓库路径，完善二方件识别和 Mock 生成流程。

## 详细变更

### 新增

1. **CFR 反编译工具集成**
   - 下载 CFR 0.152 jar 到 `bin/cfr-0.152.jar`（2.1MB）
   - 创建 `src/utils/cfr.ts` 反编译工具类
   - 创建 `src/utils/dependency.ts` 依赖解析工具
   - 支持 jar 包批量反编译
   - 自动生成类索引文件 `.dtagent/deps/index.json`

2. **自定义 Maven 仓库路径**
   - 支持 `--m2-repo` 参数指定 Maven 本地仓库
   - 自动从 settings.xml 读取 localRepository 配置
   - 解决 Windows 路径问题

3. **二方件识别逻辑**
   - 在 `generate-java-ut/SKILL.md` 中定义识别规则
   - 在 `dtagent.md` 中添加二方件处理流程
   - 在 `generate-dt-single.md` 中添加处理步骤

### 修改

1. **`/init-dt` 命令增强**
   - 新增 `--decompile <packages>` 参数
   - 新增 `--m2-repo <path>` 参数
   - 初始化时自动反编译二方件

2. **DT_AGENTS.md 生成**
   - 新增二方件信息部分
   - 记录反编译范围、类数、存储位置

3. **bin/dtagent.js CLI**
   - 支持 `--decompile` 参数解析
   - 支持 `--m2-repo` 参数解析

### 测试验证

- ✅ CFR 反编译 guava-18.0.jar 成功
- ✅ 端到端测试 config-history 项目成功
- ✅ 反编译 fastjson 等 3 个 jar，648 个类

## 命令对照表

| 命令 | 说明 |
|------|------|
| `dtagent init` | 基础初始化 |
| `dtagent init --decompile com.alibaba.*` | 初始化 + 反编译二方件 |
| `dtagent init --m2-repo D:/repo` | 指定 Maven 仓库 |

## 二方件识别规则

| 包名前缀 | 类型 | 处理方式 |
|---------|------|---------|
| `java.*`, `javax.*` | 标准库 | 直接使用 |
| `org.springframework.*` | 框架 | 有文档 |
| `org.apache.*`, `com.google.*` | 开源库 | 有文档 |
| `com.alibaba.*`, `com.taobao.*` | 二方件 | 使用反编译 |
