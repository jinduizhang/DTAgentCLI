# 使用说明：填写你的项目经验

## 文件结构

```
.opencode/skills/init-dt/experiences/
├── README.md       # 本文件
├── template.md     # 经验模板
├── mockito.md      # Mockito 框架经验
└── your-custom.md  # 你的自定义经验
```

## 添加经验

1. 复制模板：`cp template.md my-experience.md`
2. 编辑内容
3. 保存生效

## 经验文件格式

```markdown
---
title: 经验标题
type: 经验类型
tags: [标签1, 标签2]
---

## 适用场景
描述什么情况下使用

## 代码示例
代码内容

## 注意事项
- 注意点
```
