# 迭代快照: v0.3.0 - 2026-03-23

## 变更摘要

集成 CFR 反编译工具，实现二方件精准 Mock。支持自定义 Maven 仓库路径，版本检测自动跳过，完善二方件识别逻辑。

## 详细变更

### 新增

1. **CFR 反编译工具集成**
   - 下载 CFR 0.152 jar 到 `bin/cfr-0.152.jar`（2.1MB）
   - 创建 `src/utils/cfr.ts` 反编译工具类
   - 创建 `src/utils/dependency.ts` 依赖解析工具
   - 支持 jar 包批量反编译
   - 自动生成类索引文件 `.dtagent/deps/index.json`

2. **自定义 Maven 仓库路径**
   - 支持 `--m2-repo` 参数指定 Maven 本地仓库
   - 自动从 settings.xml 读取 localRepository 配置
   - 解决 Windows 路径问题

3. **版本检测功能**
   - 新增 `versions.json` 记录反编译版本
   - 版本未变化时跳过反编译
   - 自动清理旧版本反编译文件
   - 输出区分"新增"和"跳过"

4. **二方件识别逻辑**
   - 基于 import 语句识别依赖
   - 检查项目源码目录下是否存在
   - 不存在 + 匹配二方件前缀 → 需要反编译
   - 在 `generate-java-ut/SKILL.md` 中定义识别规则

### 修改

1. **`/init-dt` 命令增强**
   - 新增 `--decompile <packages>` 参数
   - 新增 `--m2-repo <path>` 参数
   - 初始化时自动反编译二方件
   - 版本检测自动跳过

2. **DT_AGENTS.md 生成**
   - 新增二方件信息部分
   - 记录反编译范围、类数、存储位置

3. **bin/dtagent.js CLI**
   - 支持 `--decompile` 参数解析
   - 支持 `--m2-repo` 参数解析

4. **移除 iterations 目录初始化**
   - 不再将 iterations 目录复制到用户项目

## 二方件识别逻辑

```
对于每个 import 语句:
  1. 提取包名
  2. 检查 src/main/java 下是否存在
     - 存在 → 项目内部代码
     - 不存在 → 外部依赖
  3. 匹配二方件包名前缀 → 二方件
```

| 包名前缀 | 项目中存在 | 类型 | 处理方式 |
|---------|-----------|------|---------|
| `com.huawei.*` | ❌ | 二方件 | 使用反编译 |
| `com.alibaba.*` | ❌ | 二方件 | 使用反编译 |
| `org.springframework.*` | ❌ | 三方库 | 有文档 |
| `com.example.*` | ✅ | 项目内部 | 直接读源码 |
