# 迭代计划

总结本次对话成果，提取优化点，更新迭代计划。

## 使用

```
/plan-dt [可选：本次核心主题]
```

示例：
```
/plan-dt
/plan-dt 二方件Mock优化
```

## 执行步骤

### 1. 总结本次对话

回顾本次对话，提取：
- 完成的工作
- 遇到的问题
- 做出的决策
- 待办事项

### 2. 更新迭代记录

更新 `templates/iterations/{当前版本}_{日期}_{类型}.md`：

**如果文件存在**：
- 在 `## 已确定方案` 部分追加新方案
- 在 `## 明天计划` 部分更新任务优先级

**如果文件不存在**：
- 创建新的迭代快照
- 填充完整内容

### 3. 输出格式

```
📋 迭代计划更新

## 本次成果
- ✅ 完成事项1
- ✅ 完成事项2

## 发现问题
- 🔴 问题1：描述
- 🟡 问题2：描述

## 已确定方案
1. 方案描述

## 下一步计划
### P0
- [ ] 任务1
- [ ] 任务2

### P1
- [ ] 任务3

📁 已更新: templates/iterations/0.2.0_20260322_optimize.md
```

## 模板结构

更新迭代记录时，确保包含以下部分：

```markdown
# 迭代快照: {version} - {date}

## 变更摘要
一句话描述核心变更。

## 已确定方案
记录讨论后确定的方案。

## 待讨论问题
记录未解决的问题。

## 明天计划
### P0 - 必须完成
### P1 - 优先完成
### P2 - 待讨论
```

## 注意事项

1. **优先级排序**：P0 > P1 > P2
2. **任务可执行**：每个任务有明确的目标和文件路径
3. **问题可追溯**：记录问题根因和讨论结论
