# 迭代快照: v0.1.0 - 2026-03-21

## 变更摘要
DTAgent CLI 初始版本发布，实现核心功能。

## 详细变更

### 新增

1. **CLI 框架**
   - bin/dtagent.js 入口文件
   - commander 命令行框架
   - chalk + ora CLI 美化

2. **init 命令**
   - Maven/Gradle 框架检测
   - JUnit/Mockito 版本识别
   - 组件安装到 .opencode/
   - Mock 经验提取
   - DT_AGENTS.md 生成

3. **generate 命令**
   - 单文件测试生成
   - 批量目录扫描
   - 并行执行支持
   - 报告生成

4. **extract-experience 命令**
   - @Mock/@MockBean 识别
   - when().thenReturn() 提取
   - 经验文件生成

5. **OpenCode 命令**
   - /init-dt
   - /generate-single
   - /generate-dir
   - /extract-experience
   - /fix-ut
   - /coverage
   - /mr-ut
   - /coverage-fill

6. **文档**
   - README.md
   - docs/packaging.md
   - docs/init-guide.md
