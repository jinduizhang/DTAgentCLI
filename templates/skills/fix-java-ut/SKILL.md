## 功能

编译验证和运行验证，修复测试代码。

**核心保证**：最终代码必须可编译。

## 执行步骤

### 1. 读取项目配置

**必须从 `DT_AGENTS.md` 读取 Maven 命令，禁止使用默认命令**：

```
if (DT_AGENTS.md 不存在) {
  执行 /init-dt 技能初始化
}

从 DT_AGENTS.md 读取:
- 编译命令: mvn test-compile [参数]
- 运行命令: mvn test -Dtest={ClassName} [参数]
```

**禁止事项**：
- ❌ 不准使用默认的 `mvn test-compile`
- ❌ 不准使用默认的 `mvn test -Dtest=xxx`
- ✅ 必须使用 DT_AGENTS.md 中的命令（含自定义 settings、profiles、JVM 参数）

### 2. 阶段1: 编译验证（必须成功）

使用 DT_AGENTS.md 中的编译命令验证编译。

**循环修复直到编译通过**：

```
while (编译失败) {
  1. 解析编译错误
  2. 修复代码
  3. 重新编译
}
```

**常见编译错误**：
- 缺少 import
- 类型不匹配
- 找不到符号
- 语法错误

**无次数限制，必须成功才能继续。**

### 3. 阶段2: 运行验证（最多10次）

使用 DT_AGENTS.md 中的运行命令执行测试。

**循环修复（最多10次）**：

```
for (i = 0; i < 10; i++) {
  if (测试通过) {
    进入覆盖率提升
    break
  }
  
  1. 分析失败原因
  2. 修复代码
  3. 重新编译验证（保证编译OK）
  4. 重新运行测试
}
```

**每次修复后必须重新编译验证**，确保编译成功。

### 4. 达到次数限制

如果运行验证 10 次仍失败：

```
1. 最终编译验证
2. 确保代码可编译
3. 输出错误报告
4. 不进入覆盖率提升
```

**保证**：即使运行失败，代码也能编译通过。

## 输出格式

**成功**：
```
✅ 修复完成

编译: 通过
运行: 通过（3次修复）
进入覆盖率提升
```

**运行失败但编译成功**：
```
⚠️ 运行验证未通过

编译: ✅ 通过
运行: ❌ 失败（10次尝试）

错误报告: .dtagent/reports/fix-report.md

代码可编译，后续任务不受影响
不进入覆盖率提升
```

## 常见修复模式

| 问题 | 修复方案 |
|------|----------|
| 编译错误 | 循环修复直到通过 |
| NullPointerException | 添加 Mock 或 @InjectMocks |
| Mock 未设置 | 添加 when().thenReturn() |
| 断言失败 | 检查业务逻辑 |

## 核心保证

1. **编译必须成功** - 不影响后续任务
2. **运行最多10次** - 避免无限循环
3. **最终代码可编译** - 无论运行是否成功
